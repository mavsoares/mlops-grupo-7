# Projeto MLOps & CI/CD

Projeto-guia da disciplina **MLOps & CI/CD**, do MBA em **BI & Data Science**.

Construído ao vivo, aula a aula, pelo professor como demonstração prática de um **pipeline de MLOps completo**, abrangendo desde o provisionamento da infraestrutura até o monitoramento em produção.

## Descrição

Projeto de classificação de denúncias do Disque-Denúncia utilizando técnicas de Processamento de Linguagem Natural (NLP) e aprendizado de máquina. A solução analisará o texto das denúncias para identificar o tipo de ocorrência e o nível de urgência (Baixa, Média ou Alta). O projeto utilizará dados sintéticos para treinamento e avaliação e adotará práticas de MLOps para versionamento, organização dos experimentos, acompanhamento de métricas e rastreabilidade dos modelos.
